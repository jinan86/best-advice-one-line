Entry for the [make.fun competition "The Best Advice I Ever Got"](https://make.fun/c/u-pangg7-the-best-advice-i-ever-got-358cefb0).

## What this program does

`main.py` writes a single sentence — the best advice I ever received — to `/output/entry.txt`. It uses only the Python standard library, makes no network calls, and is fully deterministic: every run produces the exact same 156 characters.

## The entry

> The night before my first job interview, my grandmother patched my torn shirt and said, 'Wear it — people remember how you work, not how new your shirt is.'

## How to run

```sh
python3 main.py
cat /output/entry.txt
```
